# Vue 3 + Vite
# Pasos a seguir
1_ Crear una carpeta vacia donde clonaremos el proyecto (Opcional).

2_ Copiar el link "https://github.com/CURZA-ProgWebDin/tp3-vuejs-AlexisGomez99.git", abrimos nuestro IDE utilizando la carpeta creada o elegimos el lugar donde clonar el proyecto. Ejecutar:

    * git clone https://github.com/CURZA-ProgWebDin/tp3-vuejs-AlexisGomez99.git

    Una vez clonado el repositorio entramos a \tp3-vuejs-AlexisGomez99\tp_3

    * cd \tp3-vuejs-AlexisGomez99\tp_3

    Instalamos las dependencias para poder correr nuestro proyecto

    * npm install

    Levantamos el proyecto

    * npm run dev

3_ Unez vez corriendo el proyecto nos vamos a http://localhost:5173

    Ahi veremos los 3 puntos del trabajo hechos.

4_ Para verificar los datos de la consola presionamos click derecho en cualquier parte de la pagina, y seleccionamos inspeccionar elementos. Se abrira una pestaña de herramientas de desarrollador y vamos a la parte que dice "consola" para verificar los comentarios hechos en el proyecto para cada componente.
